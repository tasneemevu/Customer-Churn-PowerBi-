## Overview

This project analyzes customer churn data from a telecom company to identify key factors contributing to customer loss. The goal is to uncover patterns in customer behavior and provide actionable insights to improve retention.

## Dataset

* Source: Telco Customer Churn Dataset (Kaggle)
* Records: ~7,000 customers
* Features include customer demographics, contract type, services, and billing information

## Tools Used

* Power BI
* Power Query (Data Cleaning)
* DAX (Data Analysis Expressions)

## Data Preparation

* Cleaned missing and incorrect values in Total Charges
* Standardized Churn column values
* Created calculated columns for Tenure Groups and Charge Groups
* Built measures for KPIs such as Total Customers, Churned Customers, and Churn Rate

## Key Metrics (KPIs)

* Total Customers
* Churned Customers
* Churn Rate

## Key Insights

* Customers on month-to-month contracts have the highest churn rate
* Customers with tenure less than 12 months are more likely to leave
* Higher monthly charges are associated with increased churn
* Customers using electronic check payment method show higher churn behavior

## Business Recommendations

* Encourage long-term contracts through discounts or incentives
* Improve onboarding experience for new customers
* Review pricing strategy for high-paying customers
* Promote alternative payment methods to reduce churn risk
